# Code of conduct

moldette follows the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

The Covenant applies to the issues, pull requests and discussions of this
repository, and to anyone representing the project elsewhere.

## Reporting

Report conduct that violates the Covenant privately through GitHub private
vulnerability reporting on this repository (Security tab, "Report a
vulnerability"), the same channel described in `SECURITY.md`. State in the
title that the report concerns the code of conduct.

The maintainer reviews every report, keeps the reporter's identity
confidential, and applies the enforcement guidelines of the Covenant.
