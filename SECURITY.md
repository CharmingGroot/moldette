# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability
reporting:
https://github.com/CharmingGroot/moldette/security/advisories/new

Do not open a public issue or pull request for a suspected vulnerability.

Include:

- affected crate and version or commit
- steps or input that reproduce the problem
- observed and expected behavior

## Response

- Reports are acknowledged within 7 days.
- An assessment follows within 30 days, with a fix plan when the report is
  confirmed.
- Fixes are prepared in a private security advisory. The advisory is
  published, and the issue reported to the RustSec advisory database, once a
  fixed version is on crates.io.

Reporters are credited in the advisory unless they ask otherwise.

## Supported versions

| Version | Security fixes |
|---|---|
| latest `0.x` minor release | yes |
| older releases | no |
